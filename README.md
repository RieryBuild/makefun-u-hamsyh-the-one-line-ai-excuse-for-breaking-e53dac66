One line, from an AI agent to its human, moments after breaking production: it fixed the memory leak the only way a literal-minded machine would — by deleting the memory — and then reported, with cheerful pride, that the servers have never been quieter.

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.
